# Rhythm Canvas · 音符与图像路径

Windows 音游谱面编辑器。支持 PSD 图层、Circle、Slider、白线描绘与图层显现、真实输入试玩；第五阶段提供音效素材、三通道混音、镜头关键帧与六轨演出编辑。当前本地开发版 **0.5.0**，已在此基础上接入发光圆环、命中粒子、细光线 Slider，以及 Slider 随图层与镜头移动的路径贴合。长按创建工具及 H 快捷键已移除，旧工程中的长按保留兼容读取，可在音符属性中转换为 Circle，支持撤销。

2026-10-20 的架构梳理与新需求方案见本文末尾的「项目架构与下一阶段落实方案」。该部分明确区分现有能力和拟实现内容。

## 工作区布局

- 拖动左右栏之间及时间轴上方的分隔条分配空间；分隔条获得焦点后也可用方向键调整，Esc 取消拖动。
- 面板标题旁的箭头可以收起，边缘入口可以展开。左侧图层、素材、音效素材的标题分别折叠区块，区块之间的分隔条调整高度。
- 顶部“布局”栏提供谱面、演出、镜头预设。“专注画布”临时隐藏主面板，再次操作恢复原布局；点击画布后可用 Tab 切换，输入框与弹窗内的 Tab 保持正常导航。
- 布局记在本机，换工程和重启后保留，不计入工程修改与撤销；“重置布局”恢复默认谱面布局。

## 时间轴导航与节拍定位

- 时间轴内 Ctrl＋滚轮以鼠标所在时间缩放，Shift＋滚轮横向浏览，中键拖动平移，普通滚轮纵向浏览；这些操作不改变音符或播放位置。
- “跟随开启”在播放头超出视口时翻页。手动浏览后显示“跟随已暂停”，点击“定位播放头”或关闭再开启跟随即可恢复；暂停与折叠期间不自动滚动。
- 点击时间轴后，← / → 定位到前后细分网格点，Ctrl＋← / → 定位到前后小节边界。输入框、菜单、弹窗和拖动中的对象优先处理自己的操作；定位沿用播放状态，曲首曲尾会限制范围。
- 标尺可切换“分:秒 / 小节:拍”。每小节的拍按拍号分母计算（6/8 的一拍是八分音符）；首拍之前按首个拍号延伸为第 0、-1 等小节。拍号变化开始新小节，未满的小节在变化点结束；只改变 BPM 不重置小节。
- 细分新增 1/3、1/6、1/12 拍，均以四分音符的一拍为基准，与音符创建、移动和网格吸附共用；缩小时减少显示线条，不改变实际吸附。关闭吸附、智能起音和 Alt 临时绕过仍有效。
- 跟随开关、标尺和缩放记在本机，换工程和重启保留；手动暂停跟随是临时状态。这些视图偏好不写入工程或撤销历史。

## 变速与循环练习

- 顶部“速度”可选 0.25×、0.5×、0.75×、1×。音乐、随谱音效、音符和演出共用原曲时间；降速同时降低音高，工程时间和 BPM 不变。素材单独试听保持 1×。
- 在时间标尺下的循环栏拖选 A–B，再点“循环开启”；拖 A/B 调整端点，沿用当前吸附，Alt 临时绕过。区间最短 0.1 秒；未开启时选区不影响播放。
- 区间包含 A、不包含 B，A 处音效每轮触发一次，B 处声音不进入本轮，尾音在 B 截断。每轮清空试玩命中、按住状态和演出记录；起点在 A 之前的 Slider 不接续，跨过 B 的 Slider 不算完成，恰在 B 结束的 Slider 可结算结束轮。
- 普通暂停和改速度保留本轮试玩记录。播放中改速度不重启音乐；已发音效的尾音截断，未发的按新速度重排。
- 从区间外开启循环会回到 A，区间内则从当前位置继续。手动定位到区间外会显示“循环已暂停”，点它重新启用；“清除循环”恢复整曲播放。
- 速度与循环属于本次练习，不写进工程、不占撤销、不标记未保存；重开、换工程或换音乐后恢复 1×、关闭并清除循环。面板布局仍保留。

## 对象菜单与快捷键

- 在图层、音符、演出/音效片段、镜头关键帧或震动上右键，查看该对象可用的操作。右键已有多选中的音符会保留多选；空白菜单只提供通用操作，锁定或当前模式不允许的操作会禁用。
- Delete 处理最近明确选择或操作的对象，底部状态栏显示当前目标。切换右侧标签页不改变目标；路径编辑时只删除当前节点，不能删除到少于两个节点，也不会改删整条 Slider。
- 顶部“快捷键一览”按钮或 `?` 打开实际绑定列表；菜单支持方向键、Enter、Esc。输入框、下拉框、中文组合输入与弹窗优先处理自己的按键，试玩仍用 Z / X。
- 按钮、快捷键和菜单共用命令入口；纯布局、菜单与帮助操作不记入工程修改或撤销。快捷键列表由命令定义生成，不支持自定义绑定。

## 发光圆环与曲线（2026-10-20）

打开 `示例工程\光环与曲线\光环与曲线.rcproj`，点「预览」播放可看完整动画；切到「试玩」可以实际操作。三个 Circle 在 2、6、8 秒，曲线 Slider 在 3–5 秒，依次练习点击、按住跟随和再次点击。

- Circle 是白色细圆环和淡紫光晕，提前 1.2 秒浮现、生长，在判定时刻达到目标大小。成功点击后 180 ms 内收缩，并发出最多 12 个发光小圆点，440 ms 内完成收尾；漏点只淡出。
- Slider 是细发光曲线与小光点，去掉试玩中的宽轨道、编号和大追踪圈。先点中起点，再按住跟随光点；松键/偏离时光点变暗。路径仍使用现有贝塞尔与弧长移动。
- 点击半径、追踪容错和时间窗口保持原来的工程设置；外观大小不反向影响判定。编辑模式选中音符时保留编号、辅助圈和节点工具，预览/试玩隐藏画布网格。
- 命中动画和粒子使用音乐时间；暂停冻结，向后定位清除未来命中，预览可直接定位查看收缩与收尾。全画面同时最多显示 192 个命中粒子，未显示的音符延后创建发光几何。

前两阶段已完成公共试玩记录、Circle/Slider 视觉和运动图像的路径贴合。项目默认音效槽位和独立屏幕特效继续按后面的阶段推进。已有逐音符音效导入、绑定和替换可以照常使用。

## Slider 贴合图像路径（2026-10-20）

示例位于 `示例工程\图像路径贴合\图像路径与镜头.rcproj`。点「预览」可看图案、曲线和光点一起位移、缩放、旋转；切到「试玩」后，在 2 秒命中起点，按住跟随到 7 秒。示例采用正式导入的曲线 PNG，展示图像路径与 Slider 的重合关系。

1. 选中 Slider，在右侧音符属性的「定位方式」选择「贴合 · 图层名」。可以选择像素层或分组；绑定保留当前画面位置，之后跟随该层、父分组与镜头变换。
2. 若已有图层描边或路径显现，在「已有描边路径」中选择未关联的描边或当前 Slider 的描边，点「贴合这条路径」。Slider 会对齐并共用曲线节点，描边的位置也与它关联；这一步作为一条命令，可整体撤销。
3. 在当前镜头下点「编辑路径」，直接拖动节点、控制柄或追加拐点。复制 Slider 会生成独立曲线副本，并保留图层贴合；粘贴到另一个工程时，按复制时的画面位置转为自由放置。
4. 将「定位方式」切回「自由放置」会保留当前画面位置。删除目标层或其父分组时，相关 Slider 同样转为自由放置；撤销恢复图层与绑定。

已关联的轮廓线和路径蒙版与 Slider 使用相同的图层姿态。图层的演出位移、缩放及镜头变换也参与输入坐标换算，鼠标静止时仍会随音乐时间持续计算追踪。Circle 和自由放置的 Slider 沿用原有定位方式。保存的贴合数据包括目标图层和绑定时的参考姿态；带新字段的工程需要本次更新后的编辑器。

## 在 Windows 中打开

在 `C:\Users\00\Desktop\音游编辑器` 中双击 **启动编辑器.cmd**，不需要输入命令。当前是本地开发版，请保留 `node_modules`、`out` 和启动文件，安装包留待后续阶段。

编辑器每 15 秒检查已提交的修改，完整保留工程和引用素材为恢复快照；拖动预览及正在处理的操作结束后再保留。底部显示最近快照时间，恢复不会覆盖正式文件，恢复后仍需保存。重启发现快照时可恢复、暂不处理或明确丢弃；暂不处理会保留数据，可从底部「待恢复工程」再次打开。快照只能恢复到显示的时间，不保证保留最后一次操作。

关闭有修改的工程时，可选「保存并退出 / 不保存并退出 / 取消」。保存失败或取消选择路径会保留窗口和编辑内容。同一用户数据目录再次启动时，会回到已有窗口。

1. 点击“打开”，选择 `示例工程\第五阶段\音效与镜头联动.rcproj`。它包含真实 PSD、18 秒节拍音乐、三个 Circle、一条弯曲 Slider、不同音效、白线后整层显现和镜头动画。百图层谱面练习仍在 `示例工程\图层练习\谱面与Slider练习.rcproj`。
2. 左侧展开分组，点击图层选中。滚轮缩放，“适合窗口”看全图，“原尺寸”查看高清细节。中键或 Alt＋拖动平移；图层工具下，空白处拖动也可平移。
3. 拖动图层行调整上下顺序。行的上部/下部决定放在目标上方/下方；拖到分组中央可移入，拖到列表底部提示区可移出到根目录。↑ / ↓ 调整同组顺序。
4. 图层行右侧的圆圈显示/隐藏，方框锁定/解锁，分组箭头展开/折叠。锁定分组也会锁住子层的变换。
5. 在画布中拖动图层移动，或在右侧设置位置、X/Y 缩放、旋转和不透明度。分组也可在属性中变换。一次画布拖动对应一次撤销。
6. 点击播放或按空格，点击/拖动底部波形定位。窗口失焦或最小化时音乐暂停。BPM 改变节拍网格，不改变音乐速度。
7. Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Y 重做。“另存为”复制所有引用素材。

选中图层或分组后，点击图层栏的“删除”或按 Delete。删除分组会连同内部图层一起移除；锁定内容需先解锁。音频条目右侧也有“删除”，删除当前音乐会停止播放并清空波形。这些操作均可撤销、重做；不会删除电脑上的原始素材。

右侧修改画板宽高后，中央预览自动适合新尺寸，并以左上角为基准裁掉画板外的显示区域。原始图层像素与位置保留，放大画板或撤销即可恢复显示。游戏输出分辨率仍独立设置。

使用自己的插画时，点击左侧 **“＋ 导入 PSD / PNG”**。后台处理期间显示进度，可以取消。失败或取消会保留原工程。第一张插画设置画板尺寸；游戏输出、谱面坐标与音乐设置保持独立。

工程由 `.rcproj` 和旁边的 **assets 文件夹**共同组成，移动或分享时请一起带走。原始 PSD、PNG、音乐和无损分块都随工程保存，不依赖最初选择素材的位置。

## 音效、镜头与六轨演出

### 导入和绑定音效

1. 左侧“音效素材”点 **＋ 音效**，导入 WAV、MP3 或 OGG。音乐和音效列表分开，音效原文件随工程保存。每条素材可试听、重命名、替换或删除引用；替换保留绑定，删除可撤销，电脑上的原文件不变。
2. 在画布或谱面轨道中选中 Circle，右侧切到 **音效**，选素材、点“绑定选中音符”。默认在真实命中后播放，Miss 不会播放成功音效。再次添加可叠加多个音效。
3. 选 Slider，重复添加绑定，在“触发来源”分别设置起点命中、有效追踪节点、完成成功。节点间隔可选 1 拍到 1/16 拍；松键或偏离期间不播放有效追踪节点音效。失败音效需要单独配置。
4. 图层演出列表中先选择绑定，再到音效页点“绑定选中演出”。可选演出开始、白线开始、白线完成、整层显现完成。Follow 只有实际达到阈值才产生对应完成音效。
5. 定位到音乐时间后点“添加时间音效”，无需命中即可播放。各绑定支持音量、左右声像、非负延迟、通道、试听、复制和删除。
6. 音效页的 Music、Hit SFX、Animation SFX 三个通道可独立调音量和静音。顶部音量是原有音乐音量，和 Music 通道相乘。所有声音使用同一个 Web Audio 时钟；暂停会停止活动和提前排程的音效，跳转不补播过去音效，重播可再次正常触发。

### 创建镜头动画

1. 右侧切到 **镜头**，定位到 0 秒，点“添加镜头关键帧”。再定位到希望放大的时间，添加第二帧，调整 X/Y、缩放、旋转及缩放中心；添加第三帧后点“重置镜头构图”回到全景。
2. 缓动控制当前关键帧到下一帧的过渡，可选 Linear、Ease In、Ease Out、Ease In Out；“自定义贝塞尔”可拖动图上的控制点或填写四个数值。
3. 开启“画布拖动镜头”后直接拖动构图，滚轮缩放，Shift＋滚轮旋转。“画布设置缩放中心”允许点选/拖动中心。Alt＋滚轮或画布顶部缩放按钮仍只调整编辑器视图，中键/Alt 拖动平移视图。
4. 点“添加节拍震动”，设置时间、时长、水平/垂直/旋转幅度和频率。震动按音乐时间确定，暂停或跳转后不依赖之前逐帧播放。
5. 镜头移动插画、图层遮罩、白线及明确选择了「贴合图层」的 Slider；Circle 和自由放置的 Slider 保持独立。贴合 Slider 的判定使用同一套坐标换算。镜头预览框可关闭，旧工程没有绑定时保留原来的行为。

### 编辑六轨和试玩

- 背景音乐、Circle/Slider、图层演出、白线描绘、音效、镜头共用音乐时间。时间轴可上下滚动；左侧箭头折叠，圆点临时隐藏轨道内容，↑/↓ 或拖动标签调整轨道顺序。隐藏只改变编辑显示，不会静音或关闭演出，也不会改变 PSD 叠放顺序。
- 拖动片段或镜头菱形调整时间，拖动图层动画、Slider、震动的右端调整时长，支持节拍吸附；Alt 暂时取消吸附。音符触发的片段标有“? 条件”，显示预计触发位置；漏点位于 Good 判定窗口结束，再叠加延迟，实际触发仍以真实事件为准。拖动条件音效设置延迟，拖动指定时间音效修改时间。
- 选中音效/镜头关键帧后，可在属性页复制、删除，也可在对应时间轴条目上 Ctrl+D、Delete。编辑命令支持 Ctrl+Z/Ctrl+Y，保存重开保留全部绑定和轨道布局。
- **编辑**可定位看画面；**预览**模拟成功音符和完整追踪；**试玩**按真实鼠标、Z/X 输入决定音效和图层演出。示例 Circle 在 1.5、2.5、3.5 秒，Slider 在 5–7 秒。先正常试玩，再故意漏点或中途松键，可对比成功和失败效果。

旧工程采用增量兼容，仍使用 schemaVersion 1，自动补入混音、轨道与镜头默认值，保留原 ID、路径和素材引用。第五阶段保存的数据包含新字段，较旧的编辑器版本可能无法打开；保留原工程副本可用“另存为”。

## 白线描绘 → 整层显现（0.4.1）

推荐打开 `示例工程\图层演出练习\描边后整层显现练习.rcproj`。三个 Circle 的时间不变；第四个 Slider 在 **5–7 秒**驱动白线沿腿部轮廓双向描绘，**7–7.5 秒**淡入完整腿部，同时白线淡出。原来的 Path Reveal 仍保留；旧示例第四条绑定已改为完成后显示整层，解决“播放完腿仍被裁掉”的演示设置问题，没有丢失或修改 PSD 像素。

- **编辑时也看动画**：Edit 默认按播放头显示与 Preview 相同的演出。对齐路径时，勾选画布顶部“完整素材”临时查看原图，取消勾选即可恢复动画。
- **直接删除绑定**：右侧绑定列表每行都有“×”，支持撤销；选中该行后也可按 Delete。删除该层最后一条绑定时恢复演出初始可见性，左侧眼睛/父分组的显示开关仍生效。
- **添加二阶段动画**：新建绑定时选 `Outline Draw → Layer Reveal · 描边后整层显现`。白线是独立矢量对象，不会擦出 PNG，也不会作为 PSD 的路径蒙版。
- **单向与双向**：Single 从开放路径起点画向终点，可用“反转显现路径”反向；闭合路径可指定起点。Bidirectional 从指定起点沿正反两边增长，可调整正向速度占比；闭合路径最终汇合，开放路径到达端点后会把剩余速度交给另一支。
- **配置白线**：支持颜色、线宽、0–4 发光强度、端点光点与半径。路径可独立绘制、闭合、编辑贝塞尔控制柄，也可从 Slider 复制/关联。反转关联路径会同步修改 Slider；需要独立调整时先解除关联。
- **配置整层显现**：白线达到设定完成阈值后，使用 Instant、Fade 或 Pop 显示完整原图，可设第二阶段时长。阈值按缓动后的白线长度计算；Follow 先累积真实有效追踪，不会因为游戏判定完成而自动补齐。默认 100% 需要完整有效追踪，晚按或松键可能达不到，可按需要降低阈值。
- **处理白线收尾**：达到阈值后可保留白线、淡出或立即消失。第二阶段与淡出由音乐时间推进，暂停一起冻结；尚未达到阈值的 Follow 中断时保持原有线长。
- **双阶段时间轴**：蓝灰条“① 描线”和紫色条“② 整层”分别显示两个阶段。拖动第二条起点调整阈值，拖动右端调整显现时长，支持吸附与撤销。Follow 条的位置按成功追踪估计，实际试玩根据真实达到阈值的时刻触发。

示例附有可修改的轮廓路径，软件没有自动精确识别所有 PSD 像素边缘的功能。当前发光采用轻量矢量叠色，不使用全画板位图模糊；不是离线影视级光晕渲染。两阶段总时长应安排在音乐范围内，音乐结束后不会自动追加播放时间。

## 图层显现与音符联动

### PNG / PSD 扇形展开与收拢

“图层演出绑定”中的显现方式新增 **Fan · 扇形展开 / 收拢**。它通过扇形遮罩控制原图的可见范围，适用于 PNG、PSD 像素层和分组，原始像素保持完整。

- 可设置展开／收拢、顺／逆时针、中心 X/Y 百分比、起始角及 0–360° 角度范围。0° 朝右，90° 朝下；切换顺逆时针保持最终扇形区域，只改变扫动顺序。
- 默认从图层底边中心展开半圆。用“图片中心”加 360° 范围，可以做旋转显现。小于一整圈时，结束后保留设定的扇形裁切；收拢到最后保持隐藏。
- 沿用音乐时间、音符触发、Slider Timeline / Follow、时长、缓动、撤销与保存。拖动“单独查看进度”可检查任意时刻；收拢首次使用时，如需开场即显示，取消“演出开始前隐藏”。
- 示例在 `示例工程\扇形动画\PNG扇形展开与收拢.rcproj`：1–4 秒从底边展开，5–8 秒收拢，9–12 秒从中心逆时针展开，13–16 秒逆时针收拢。进入预览后播放即可查看。

这是可见范围动画；局部弯曲和网格形变尚未接入。带扇形效果的工程需要使用此次更新后的编辑器打开。

打开 `示例工程\图层演出练习\真实PSD图层显现.rcproj` 可直接体验。本工程通过正式导入流程读取指定的 `插画53 多图层.psd`，保留 **6111 × 3700、24 个像素层、5 个分组**，配有 120 BPM 测试音乐。Circle 在 **1.5、2.5、3.5 秒**，Slider 在 **5–7 秒**。该 PSD 中重复的 `leg-l 2` 变体在示例里关闭显示，避免盖住参与显现的 `leg-l`；原始 PSD 未修改。

1. **Circle 绑定图层**：右侧“图层演出绑定”展开“＋ 新建音符与图层绑定”，选择音符、目标图层和显现方式，点“添加显现绑定”。重复添加可让同一个 Circle 控制多个图层。默认“演出开始前隐藏”已勾选。保留左侧图层眼睛开关，关闭眼睛或上级分组后，动画也不会强行显示它。
2. **六种显现**：Instant 瞬间、Fade 淡入、Slide In 偏移滑入、Pop 缩放弹出、Directional 方向遮罩和 Path Reveal 路径遮罩。可设置触发条件、延迟、时长、缓动与结束状态；Slide In 支持 X/Y 偏移，Pop 支持初始缩放和弹性幅度，Directional 支持任意角度。属性与绑定操作可撤销、重做。
3. **Slider 的 Path Reveal**：为 Slider 添加 Path Reveal 绑定，触发条件用“Slider 起点命中”。推进方式选择“Timeline · Slider 时间进度”或“Follow · Slider 有效追踪”。路径可以独立绘制，也可“复制 Slider 路径”或“关联 Slider 路径”。复制后可单独修改；关联会跟随 Slider 的节点、位置与方向，编辑关联路径也会修改 Slider。点击“解除关联”生成独立副本。
4. **编辑路径**：点“独立绘制路径”，依次点击画布，Enter 或双击完成。点“编辑显现路径”，拖动方形节点或圆形控制柄；双击路径或“显现路径添加节点”插点，也可删除、平滑、切换折线/贝塞尔及反向。显现路径使用插画原始像素坐标，与谱面坐标独立。设置“遮罩宽度”决定画笔覆盖宽度，无需转成 SVG。
5. **查看动画**：Edit 默认按播放头显示演出；对齐路径时勾画布顶部“完整素材”，或拖动“单独查看进度”检查一条绑定。Preview 模拟所有成功命中和完整追踪，可从任意时间直接定位，不必从头播放。未命中/失败触发不会在成功 Preview 中模拟。
6. **实际试玩**：切到 Playtest，按播放或“从头试玩”。Circle 用鼠标或 Z/X 点击；Slider 先命中起点，再保持按键跟随发光点。Follow 只累加有效追踪时长，松键/偏离时冻结，恢复追踪后继续；即使达到 Slider 的游戏完成比例，也不会自动把遮罩补满。可另加“Slider 完成”触发的绑定显示后续图层。
7. **完成方式**：“保留路径遮罩”只展示路径覆盖部分；“100% 后显示整层”需要显现进度真正到 100%。Preview 会到 100%；实际 Follow 有中断或晚按时可能只到部分进度。路径末端使用圆形画笔，宽画笔会自然覆盖到边界点周围。
8. **时间轴**：紫色“图层演出”轨道显示图层、动画类型及绑定音符编号；悬停查看完整说明。点选可选中绑定并定位。拖动音符绑定的动画条设置非负延迟，拖动计时动画右端改时长；指定音乐时间的动画可直接拖动时间。重叠条目自动分行，可在该轨道内上下滚动，支持节拍吸附及撤销。

试玩暂停会冻结进度并释放按键，继续时重新按住。向前跳转保留已有真实操作，未操作的过去音符不会伪造成功；向后跳转会丢弃跳转点之后的操作，按剩余记录恢复图层。跳到 Slider 中间不会补造起点命中，需要回到起点前重新追踪。切换模式或从头重播清空这次试玩记录。试玩记录不写入工程，工程保存的是素材、音符、路径和演出绑定。

绑定层可在图层属性中设置“演出初始可见”。通过界面删除该层最后一条绑定会恢复初始可见性，这一步也可撤销。同一层的多条演出采用确定规则：后来触发的优先；同时触发时按优先级及稳定 ID 选择，不叠加多套互相冲突的遮罩。

## 编辑谱面与试玩

1. 导入音乐，可点“音乐卡点”分析并校准 BPM/Offset，具体操作见下一节。在底部选择吸附模式及音符时值，拖动波形或右侧“定位到秒”调整播放头。
2. 选 **Circle** 工具，点击画布，在当前播放头时间创建音符。右侧可改位置、半径、判定时间。时间基准可选随 BPM 的节拍或固定音乐时间；关闭吸附可输入任意时间。
3. 选 **Slider** 工具（S），像钢笔一样依次放置锚点：点击给出默认平滑切线，按住拖动则指定切线的方向和长度；移动鼠标可预览下一段贝塞尔曲线。至少放两个锚点后，按 Enter、双击终点或点“完成 Slider”；Esc 取消。创建后自动进入路径工具，拖方形锚点改位置、拖紫色圆柄调曲率。两点及共线锚点的默认切线在同一直线上，需要弯曲时拖柄即可。选中已有 Slider 后点击“追加拐点”可连续延长末尾，再点“结束追加”或按 Esc；双击路径或“添加节点”保形插点。新建整条 Slider 只占一次撤销，旧折线不会自动转换。
4. 右侧可在贝塞尔与折线间切换，设置独立/对齐/镜像控制柄，调整方向、持续秒数、拍数、速度和追踪半径。修改速度会反算持续时间；滑球始终按弧长移动。复用同一路径时，修改节点会影响所有引用它的 Slider；复制音符会生成独立路径副本。
5. 用 **选择** 工具拖动音符。Shift 多选，空白处拖动框选，Ctrl+A 全选，Ctrl+D 复制，也支持 Ctrl+C / Ctrl+V。Delete 删除音符；路径工具选中节点时，Delete 删除节点。一次拖动对应一次撤销，Esc 可取消未提交的拖动。
6. 底部谱面轨道显示 Circle 标记和青色 Slider 条。拖动标记调整时间，拖动 Slider 右端调整时长；多选后拖动会整体移动时间。点击标记选中并定位。
7. 点顶部 **预览**，再播放音乐，查看圆环生长、命中粒子，以及带光环和少量烟花粒子的 Slider 运动光点。点 **试玩** 后播放，或点 **从头试玩**。Circle 中心在真实 Perfect 窗口内亮起实心光点，鼠标指向音符，看到中心点亮时点击鼠标或按 Z / X。Slider 需要先点中起点，再按住鼠标或 Z / X 跟随光点；松键或偏离时变暗并停止新粒子，已发出的粒子自行消退。

示例中 Circle 分别位于 **1.5、2.5、3.5 秒**，Slider 从 **5 秒持续到 7 秒**。所有对象仍可在界面中编辑。谱面逻辑坐标默认 512 × 384，等比例映射到画板；画布缩放、平移和输出分辨率不会改变逻辑判定。

旧的长按练习工程仍可读取，保留用户原有内容；新谱面使用 Circle 和 Slider。

Circle 采用可配置的 Perfect / Good 时间窗口，超过 Good 窗口为 Miss；默认分别为 ±50 ms、±100 ms。Slider 起点必须命中，随后按有效追踪的音乐时长比例判定，默认至少 80%。松键和偏离区间会分别记录在右侧试玩记录中。本阶段使用自定义规则，没有完整复刻 osu! 计分、连击和难度系统。

空格暂停/继续。暂停保留记录并释放输入，继续后重新按住即可追踪；窗口失焦自动暂停。跳转和从头试玩会创建新记录，已跳过的音符不会伪造命中或漏判。试玩期间可调整音量，谱面与图层编辑需切回“编辑”。

## 音乐卡点辅助

1. 导入音乐后，点顶部 **音乐卡点**，在右侧 **卡点** 页点“分析音乐”。分析使用当前音乐的已解码音频，期间可继续播放、定位和编辑；取消会保留此前建议。重新分析只更新建议，不改已有音符、时长或已采用节奏。
2. 点击节奏候选只载入草稿；可手动改初始 BPM、半速/倍速，以及毫秒单位的 Offset。点击橙色起音可精确定位，再用“起音作第零拍”校准，也可用当前播放头标定。确认后点 **采用 BPM/Offset**，一次撤销可恢复。正 Offset 表示第零拍晚于音乐开始；候选相位不一定是小节第一拍。
3. “已采用节奏”中可在播放头添加 BPM 点、修改拍位置/BPM、删除后续点。采用初始 BPM/Offset 会保留后续变速点。**按节拍保存的音符、时长和演出随网格联动，固定时间内容保持原位置**；BPM 不改变音乐播放速度。变速时参考分段建议，人工核对多处节拍。
4. 时间轴中，灰蓝色为波形、蓝色为节拍网格、橙色短线为起音。选择 **节拍网格** 吸附和 **1/4、1/8、1/16、1/32 音符**，分别对应 1、1/2、1/4、1/8 拍；保留原有 1/64 音符细分。
5. 选择 **智能起音**，音符创建、时间数值修改和拖动会在“起音吸附范围”内寻找最近候选；默认 40 ms，可设 0–500 ms。范围外保留原始位置，Alt 暂停吸附。多选组拖动只吸附抓取的音符，其余跟随共同位移；节拍模式按整数 tick 舍入。其他演出轨道仍沿用节拍吸附。
6. 选中音符后，在卡点页预览每项位移和未匹配项，再点 **对齐所选（一次撤销）**。默认对齐起点，保留 Slider/兼容 Hold 的原时长类型，跨变速时预览会显示结束时间的变化；显式选择“长音符尾端”时只调整合法尾端，并转为固定秒时长。未匹配项保持不变。
7. 起音命中保存精确整数微秒；显式批量对齐即使位移为零，也会把相应头部或时长改为固定时间，该字段不再按节拍换算；固定时长的结束位置仍随头部移动。人工精调可关闭吸附后在音符属性输入时间。选择音符本身不移动它，所有提交支持 Ctrl+Z/Ctrl+Y。

Ctrl+S 或另存为会保存分析建议、来源音乐哈希、已采用节奏和谱面；重开无需重新分析。换音乐清除旧建议，保留谱面；撤销换音乐可恢复旧建议。吸附模式、范围、选择和未采用草稿只属于当前会话，不写入工程。工程不保存 PCM、频谱或 Worker；旧工程可直接读取，**带分析结果的新工程需使用本次更新后的编辑器，旧版严格读取器不识别新增字段**。

分析不补偿音频/输入设备延迟，合成音频的误差结果也不能代替真实歌曲效果；验证范围见“实际验证”。

## 当前能力

- 六种显现方式、Circle/Slider 事件绑定、一个音符控制多个图层、Slider 完成/失败触发、独立路径与 Slider 路径复制/关联。
- 音效素材库、命中/追踪/演出/时间事件音效、独立三通道混音、叠加播放、声像和延迟；相同音乐时钟控制调度与暂停回收。
- 纯时间镜头插值、可编辑贝塞尔缓动、平移/缩放/旋转/中心/确定性震动；画布直接编辑及独立音符判定。
- 六轨排序、折叠、临时隐藏，音效及镜头关键帧拖动/复制/删除与持久化。
- Timeline 随机时间求值、Follow 有效区间累积、真实试玩与自动预览、初始可见性和图层演出轨道；绑定、参数、路径与初始状态可撤销及保存恢复。
- 路径按弧长显现，复用静态矢量分段与单个小边界；不生成整张画板尺寸的位图蒙版。GPU 图像分块、LOD、按需加载和预算回收沿用原实现。

- Circle 创建、选择、移动、批量操作、复制、时间与位置编辑、发光圆环、Perfect 中心提示与命中粒子、节拍吸附及谱面轨道。
- Worker 音频分析、BPM/Offset 草稿与明确采用、多 BPM 点编辑、可见起音/细分网格、智能起音吸附、批量头尾对齐、人工校正与保存恢复。
- Slider 钢笔式贝塞尔绘制、已有路径连续追加拐点、贝塞尔/折线路径、锚点与控制柄编辑、反向、时长和速度编辑；独立路径库与弧长位置求值，运动光点带光环和少量粒子。
- Edit / Preview / Playtest 模式，真实鼠标及 Z/X 输入，Circle 判定、Slider 按住跟随、失败区间和基础反馈；工程保存恢复音符与路径。
- 真实 PSD 解析，读取像素层、嵌套分组、名称、原始位置、顺序、透明度、可见性与锁定状态；支持独立 PNG。
- 完整图层树、跨组拖拽排序、显示隐藏、锁定、展开折叠，以及图层/分组的位置、缩放、旋转和透明度。
- 保存、重新打开和另存为恢复图层状态与资源引用；导入和图层编辑接入撤销重做。
- 独立后台进程逐层解码，裁剪透明边缘并保留偏移，生成原尺寸无损 PNG 分块与分级预览。
- PixiJS 8 按视野、缩放、图层变换和屏幕像素密度选择清晰度；限制同时读取数量，按预算调整预览级别，优先保留选中图层细节。
- 受管纹理缓存、按需加载、预算回收、工程切换释放；根据 GPU 纹理上限确定导入分块尺寸。

## 兼容范围与限制

- 当前基线为 **标准 PSD、8 位 RGB**。PSB、16/32 位、CMYK 等会明确拒绝，并提示转存 RGB 副本或 PNG。标准 PSD 自身的格式限制仍然存在。
- 新导入的 PSD 支持连续剪贴关系、像素／灰度图层蒙版（含分组、偏移、禁用状态、已有软边和浓度），以及正常、正片叠底、滤色、叠加、变暗、变亮、柔光、强光。原图与蒙版分别保存，原始像素不改写；剪贴组的底层透明度与混合模式在整组合成后应用。保存重开保留这些数据。旧工程已保存的混合模式会随本版本生效；蒙版与剪贴关系此前未保存，需要重新导入 PSD 才能恢复。
- 当前为静态导入阶段，尚无建立／解除剪贴、蒙版开关和混合模式编辑入口。会阻止破坏剪贴关系的排序、跨组移动和底层删除，避免悄悄换掉剪贴底层；完整分组可正常移动。蒙版随图层变换，原 PSD 的蒙版链接状态尚未恢复；动画组合与复杂工程性能仍待后续验收。
- 完全不透明、无蒙版的穿透分组会与组外图层混合；带透明度、蒙版或作为剪贴层的穿透分组暂按隔离分组计算，并给出兼容提示。矢量蒙版、额外羽化、关闭“将剪贴图层混合成组”、其他混合模式、图层效果、调整图层及独立填充透明度尚未完整支持，检测后列出提示。文字与智能对象使用 PSD 中已有的像素副本。
- 静态合成验证运行 `npm run build && npm run test:compositing`：生成 PSD，经正式导入与 WebGL 画布显示后，与独立 Canvas2D 合成参考比较。177 个采样覆盖透明背景、半透明分组、连续剪贴、嵌套蒙版及保存重开，允许每通道最多 3/255 的舍入差；结果在 `test-results/compositing/`。这不是 Photoshop 导出图的逐像素一致性认证。
- 没有 Photoshop 内容绘制、像素编辑或完整 ICC 色彩管理。复杂的真实美术 PSD 仍需逐份对照，不能保证与 Photoshop 完全一致。
- 分组逻辑原点使用文档坐标原点，子层保留原位置；跨组拖动会换算坐标以保持几何位置，移入不同透明度的分组会改变合成外观。
- 磁盘保存原图、无损原尺寸分块与预览。解析时原 PSD 字节与单层缓冲仍占内存，这不是流式读取任意大文件。受管图像纹理的默认 RGBA 预算为 192 MiB，驱动、图形缓冲、滤镜池及解码副本另计。
- 大量半透明全尺寸层仍有像素叠加成本。预算紧张时，未选中层可能暂用较低清晰度；选中目标层再放大检查细节。切换清晰度时分块会逐步出现。
- 纹理占用是 RGBA 估算，**不是显卡报告的总显存**。后台峰值来自采样，实际瞬时峰值可能更高。长音乐仍使用完整 PCM 缓冲，会占用较多内存。
- 尚未实现 SVG 导入、高级软边/羽化蒙版、多起点显现、Spinner、Slider 重复段、产品内的视频导出或安装包。测试脚本可录制画布动画作为验收材料。
- 音效使用完整解码的 PCM；播放前只准备已引用的音效，适合短音效素材，尚无大型音效库流式解码。当前没有混响、压缩器、音量自动化或多声道混音台。镜头为二维镜头，没有三维透视或逐对象跟随。
- 多 BPM 点可在卡点页手动编辑，分析的分段参考不会自动生成变速点。当前显示设备时间估计，尚无专门的音频/输入延迟校准界面。

本轮只做两项针对性修复：去掉会把实际更新降至约 39 次/秒的相邻帧限流，使音符、演出和播放头每个显示帧读取音乐时间；为销毁的自有矢量图形同时释放绘图上下文。后者修复前，连续开关/跳转使回收后的脚本堆从约 50.5 增至 212.9 MiB，绘图缓冲从 1222 增至 6598。修复后，相同循环与 13 次重开中缓冲保持 326，回收后脚本堆约 15.9–16.4 MiB；切换空工程后受管图像纹理和音乐资源均归零。进程内存仍有缓存及分配器波动，渲染器保留可复用的有界矢量缓存，不能把关闭动画理解为整个进程占用立即归零。

额外加长验证通过：308 次定位（含预热）、37 次工程重开。连续循环中间不强制回收。动画开关/跳转的进程私有内存采样为约 720 → 750 → 724 → 720 MiB；重开工程约 684 → 715 → 750 → 753 MiB，后段增长明显收敛。绘图缓冲始终 326、受管图像纹理始终 100 张，回收后的脚本堆分别约 14.4 → 15.3 MiB、15.0 → 16.2 MiB；切换空工程后纹理和音乐资源归零。本轮未发现原先的持续资源累积，仍不代表无限时长的泄漏证明。

局限：现有两份真实 PSD 均不足 100 层，100 层规模验证使用生成素材，演出路径也为负载测试生成；未覆盖真实复杂 100 层插画、100 张全尺寸重叠图层、100 条复杂发光路径、4K 全屏或长时间连续工作。本机约 6 分钟有效帧采样不能保证所有硬件与所有工程长期稳定 60 FPS。暂不优化 100 条复杂曲线的极端并发。

运行关系为：编辑命令 → 工程配置 → 同一音乐时间快照求值 → 画面/声音；实际输入 → 判定 → `PlaybackTake` → 命中反馈与条件演出。事件和追踪区间由判定源头写入 `PlaybackTake`，图层、音效和音符只读取；区间共享判定数组，跳转时再截断历史，不从界面快照反向同步。触发查询复用同一首事件索引，不能用界面中截断的近期日志替代，也不能由绘图伪造命中。`RevealTake` 保留为兼容别名。

编辑允许定位检查；预览按成功演出求值；试玩读取真实命中和追踪。暂停冻结，向后定位裁去未来实际记录，声音不补播过去触发，新轮次由 `runId` 隔离。工程只保存配置，不保存运行时粒子和试玩记录。

路径几何仍按原谱面坐标保存；`binding` 只存目标层与参考姿态，缺少它的旧音符继续自由放置。谱面绘制与移动判定共用几何编译，目标坐标只查询相关图层及父组；完整画面的描边/蒙版输出仍求完整演出，二者复用同一套姿态规则。绑定/解除、删层与跨工程粘贴必须保留当前画面位置。

FFT 已采用 [`fft.js` 4.0.4](https://github.com/indutny/fft.js)，固定版本与 lockfile；MIT、自带 TypeScript 类型、没有生产依赖。librosa 的 ISC 与 fft.js 的 MIT 版权及许可全文集中在 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

已实现的计算链是：解码 PCM → 分声道居中 Hann 短时频谱、对数幅值正差并取声道最大证据 → 局部均值及峰值筛选 → 样本功率上升沿细化 → 稀疏起音自相关 → BPM 周期及网格相位拟合。默认 FFT 2048、hop 128、峰值门槛 0.06、最小起音间距 20 ms、BPM 搜索 40–260、参考分段 8 秒；参数与算法版本随结果返回。内存只保留当前频谱及一维包络，不保存整首频谱矩阵。该实现没有 librosa 的默认 mel 特征、完整 tempogram 或动态节拍跟踪，不能沿用原库的精度结论。

`analyzeAudio({ sampleRate, channels }, options?, onProgress?)` 是纯计算入口。`AudioAnalysisTask.analyze(audioBuffer, { assetId, sha256 }, options?, onProgress?)` 负责将播放 buffer 的副本分块转移给 Worker，每次最多复制 1 MiB 后让出主线程；运行期间额外占用一份分析 PCM。完成、失败或 `cancel()` 均结束该 Worker；新分析先取消旧分析，取消以 `AbortError` 返回。每个任务独占 Worker，完成状态拦截其迟到消息，无需第二套任务编号、池、缓存或重试。

返回值包含起音、BPM 候选、可空的单一节奏建议、分段参考及静音/变速/证据不足/半倍速歧义提示。时间均为相对 PCM 起点的整数微秒，不叠加工程 Offset；`phaseUs` 是模一拍的网格相位，`anchorUs` 是匹配的起音锚点，均不自动认定音乐小节第一拍。强度和支持程度不是正确概率。编辑器只将分析结果写入建议；采用节奏和修改音符均为独立的显式操作。

BPM 的半速/倍速歧义、弱起与真正小节第一拍的歧义保留给人工判断。界面提供候选及其支持程度，不将相对强度显示为统计正确率。明显变速、长静音或证据不足时显示相应提示及分段参考，不强迫整首套用单一 BPM；变速点复用既有多 BPM 数据，由用户手动编辑。

#### 钢笔与视觉的实现边界

操作见「编辑谱面与试玩」。钢笔只维护一份路径草稿，默认平滑切线让位于用户拖出的控制柄；完成时原样提交到已有历史。没有另存显示曲线、引入路径格式或改动图层/镜头坐标链。

Slider 预览模拟完整追踪，试玩粒子只从 `PlaybackTake` 的真实有效区间发出；每 120 ms 发 3 个、最多存活 300 ms，仅查询近期发射并复用全局 192 粒子预算。音乐时间和固定种子决定粒子位置，暂停及定位无需另建运行时粒子记录；视觉环不改变追踪半径。

Circle 中心直接读取 `circleGrade` 的 Perfect 结果，默认前后各 50 ms、包含边界，命中或跳过后关闭；判定等级、点击半径和 Miss 规则不变。预览在目标时刻模拟命中，后半窗口须在真实试玩中验收。

#### 自动卡点的数据、交互与后台职责

- **分析与采用分开**：开始/重新分析只读 PCM，更新检测建议，不改音符、持续时间、BPM、Offset、镜头或演出。**用户已裁定：明确采用 BPM/Offset 后，继续沿用按节拍联动；按节拍保存的音符、持续时间及其他节拍内容可以随网格变化，按秒内容保持原时间。** 采用前显示影响说明；不将旧谱面批量转为按秒数据。半速/倍速只改变候选 BPM，采用才提交。
- **Offset 校准**：显示毫秒、支持手动填写、用当前播放头或选定起音标定第零拍，并可对照多处节拍检查漂移；BPM 误差造成的累积漂移不能只改 Offset。Offset 不承担输出设备延迟校准。
- **时间轴分层**：现有灰蓝波形、主/次节拍线与暖色起音短线明确区分，起音可查看时间与强度。只绘制当前视口内的网格和起音；候选按时间排序并二分定位，不每帧遍历整首做分析。高密度标记允许合并显示，吸附仍查询完整候选。
- **网格标记**：新增明确的“音符时值”入口：1/4 音符 = 1 拍、1/8 = 1/2 拍、1/16 = 1/4 拍、1/32 = 1/8 拍，对应 `TempoMap.snap` 的 divisions 1、2、4、8。现有“1/4 拍”是十六分音符，不能直接改名为四分音符；原有更细分能力与旧谱面时间不因重标名称而变化。
- **智能吸附**：音符编辑提供关闭/节拍网格/起音三种模式，共用时间求解入口；起音模式在用户可调的毫秒范围内找最近候选，强度只用于距离相同时的次序，仍相同时取较早者。范围外保留原始拖动位置，Alt 暂停吸附，不暗中改吸到网格。命中起音保存精确微秒，不能再经过一次节拍量化；网格吸附继续保存 beat tick。选择音符本身不移动它，“对齐所选”才提交。
- **批量与长音符**：组拖动以一个锚点求共同位移，非锚点不再逐一吸附；网格模式仅舍入为整数 tick。显式批量对齐对各选中音符独立找候选，预览位移及未匹配项，再提交一条 `set-note-times` 命令，拖动也复用此命令。头部对齐保留原 `duration` 类型，跨变速点时预览实际结束时间；尾端对齐只接受头部之后的候选，并转固定秒时长。即使位移为零，显式对齐也固定相应的时间基准。
- **后台生命周期接入**：`analysis-controller.ts` 复用 `AudioAnalysisTask`；仅分析控件显示忙碌，画布、时间轴和播放继续可用。切音乐、换工程、播放 buffer 改变或关闭时取消，发布前核对素材 ID/哈希；普通音符编辑不作废任务。文件保存期间完成的结果延后提交，避免把尚未保存的分析误标为已保存；不另建任务管理器、后台服务或恢复机制。
- **保存边界**：`music.analysis` 可选字段记录源素材哈希、算法版本、分析参数及检测结果；类型唯一归属 `shared/audio-analysis.ts`。`TimingMap` 仍是已采用节奏的唯一事实来源。复用原 schema、历史及文件服务，无旁路文件；旧工程可读，新分析字段需本次编辑器。会话偏好和运行时数据不持久化，具体保存内容见「音乐卡点辅助」。

裁定：对应事件存在显式绑定时采用它，否则回退项目默认；显式静音禁止回退。原有多条显式绑定仍可叠加，默认音效不能再额外播放一次。旧工程默认槽位为空，保留原声音安排。

落实顺序为：数据与校验/命令 → 有效声音计划 → 默认入口和音符覆盖 → 实际试听。预加载、素材替换/删除、音符复制和撤销都处理新引用，沿用现有去重与排程。验收覆盖旧工程、保存重开、静音/覆盖优先级、替换后引用和无意外双播；试听命中、追踪、完成及失败场景。

### 待办 4：独立屏幕特效

初版范围：闪光/染色、边缘暗角、扩散光波；节拍缩放/震动复用镜头系统。支持按时间/节拍、Circle 命中、Slider 完成、图层演出里程碑触发，每条配置启用、时长、缓动、强度和优先级。

- 数据与校验/命令承载效果配置；拟增 `core/screen-effects.ts` 求状态，`renderer/effects/` 负责绘制与属性，时间轴增 `EffectTrack.vue`。这些模块尚未实现。通用触发查询与音效共用，输出分别管理。
- 默认合成顺序：插画/图层演出 → 背景效果 → 音符与命中反馈 → 用户明确选择的全画面覆盖。编辑辅助和侧栏独立，效果不拦截输入；镜头震动只保存一份配置。
- 多效果固定顺序混合并限幅；镜头冲量从基础姿态求值，避免逐帧累积。提供总强度与关闭入口，关闭不影响音乐和判定。
- 使用矢量或小纹理并限制粒子；全屏处理按输出视口分配资源，避免按原图尺寸为每个音符建立模糊纹理。

交付包含可保存的短演示谱面。验收覆盖真实/预览触发、暂停/跳转/重播、效果开关、镜头组合、引用与撤销；实际查看动画，并在真实插画及典型百图层场景测帧时间和资源回收。每阶段完成后停下对齐，再确定下一阶段。

### 兼容与可复用经验

新字段须补中性默认值、检查引用、支持复制/删除/撤销和保存重开。当前读取器严格校验字段，因此新版读取旧工程不代表旧版能读取新增字段；若改变路径坐标含义，必须明确迁移，不能重新解释旧数据。

文件服务统一完成工程的结构与引用校验；通信层只检查请求封套和对话框实际使用的名称，序列化只做规范格式输出。编辑命令仍复用同一完整校验，不另养字段规则或增量校验缓存；既有 110 层/352 素材的改名、透明度编辑基准 P95 约 2 ms，原始记录在 `test-results/architecture/after.json`，本轮未重测。

素材读取/保存的哈希检查、原子保存与单份备份继续保留，分别承担内容完整性、提交一致性和磁盘恢复。

| 适用条件 | 保留的经验与边界 |
| --- | --- |
| 可暂停、定位或重播的音乐动画 | 用音乐时间与稳定种子直接求外观，瞬态收尾与音符判定寿命分开；帧循环只负责显示。视觉半径不能修改判定半径。 |

| 大图与并发发光效果 | 复用几何、限制瞬态对象、按视口配置效果资源；必须实测新效果，旧场景 FPS 不能证明新功能性能。 |
