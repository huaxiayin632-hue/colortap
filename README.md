# Rhythm Canvas · 阶段 2

Windows 音游谱面编辑器，基于第一阶段继续开发。目前完成 PSD 导入与图层管理，停在阶段 2。

## 在 Windows 中打开

在 `C:\Users\00\Desktop\音游编辑器` 中双击 **启动编辑器.cmd**，不需要输入命令。当前是本地开发版，请保留 `node_modules`、`out` 和启动文件，安装包留待后续阶段。

1. 点击“打开”，选择 `示例工程\图层练习\6000像素图层练习.rcproj`。它通过实际 PSD 导入生成，含 100 个像素图层、10 个分组和一首 18 秒节拍音乐。
2. 左侧展开分组，点击图层选中。滚轮缩放，“适合窗口”看全图，“原尺寸”查看高清细节。中键或 Alt＋拖动平移；空白处拖动也可平移。
3. 拖动图层行调整上下顺序。行的上部/下部决定放在目标上方/下方；拖到分组中央可移入，拖到列表底部提示区可移出到根目录。↑ / ↓ 调整同组顺序。
4. 图层行右侧的圆圈显示/隐藏，方框锁定/解锁，分组箭头展开/折叠。锁定分组也会锁住子层的变换。
5. 在画布中拖动图层移动，或在右侧设置位置、X/Y 缩放、旋转和不透明度。分组也可在属性中变换。一次画布拖动对应一次撤销。
6. 点击播放或按空格，点击/拖动底部波形定位。窗口失焦或最小化时音乐暂停。BPM 改变节拍网格，不改变音乐速度。
7. Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Y 重做。“另存为”复制所有引用素材。

选中图层或分组后，点击图层栏的“删除”或按 Delete。删除分组会连同内部图层一起移除；锁定内容需先解锁。音频条目右侧也有“删除”，删除当前音乐会停止播放并清空波形。这些操作均可撤销、重做；不会删除电脑上的原始素材。

右侧修改画板宽高后，中央预览自动适合新尺寸，并以左上角为基准裁掉画板外的显示区域。原始图层像素与位置保留，放大画板或撤销即可恢复显示。游戏输出分辨率仍独立设置。

使用自己的插画时，点击左侧 **“＋ 导入 PSD / PNG”**。后台处理期间显示进度，可以取消。失败或取消会保留原工程。第一张插画设置画板尺寸；游戏输出、谱面坐标与音乐设置保持独立。

工程由 `.rcproj` 和旁边的 **assets 文件夹**共同组成，移动或分享时请一起带走。原始 PSD、PNG、音乐和无损分块都随工程保存，不依赖最初选择素材的位置。

## 当前能力

- 真实 PSD 解析，读取像素层、嵌套分组、名称、原始位置、顺序、透明度、可见性与锁定状态；支持独立 PNG。
- 完整图层树、跨组拖拽排序、显示隐藏、锁定、展开折叠，以及图层/分组的位置、缩放、旋转和透明度。
- 保存、重新打开和另存为恢复图层状态与资源引用；导入和图层编辑接入撤销重做。
- 独立后台进程逐层解码，裁剪透明边缘并保留偏移，生成原尺寸无损 PNG 分块与分级预览。
- PixiJS 8 按视野、缩放、图层变换和屏幕像素密度选择清晰度；限制同时读取数量，按预算调整预览级别，优先保留选中图层细节。
- 受管纹理缓存、按需加载、预算回收、工程切换释放；根据 GPU 纹理上限确定导入分块尺寸。
- 普通隔离分组先合成再应用透明度，滤镜区域限制在可见视野，避免直接创建全画板大小的临时纹理。
- 保留第一阶段的工程管理、音乐播放/暂停/跳转、波形、统一音频时钟、BPM 与时间轴吸附。
- 运行记录提供导入耗时、后台内存采样峰值、进程内存、界面和 Pixi 绘制循环帧时间、受管纹理占用估算，可导出 JSON。

6000 × 6000 和 100 层是工作规模，不是代码设置的尺寸或层数上限。原始素材、原尺寸分块、逻辑图层、GPU 纹理、画板与输出尺寸独立；工程不保存 Vue/Pixi 对象。缩小预览不会覆盖原图，放大时按需读取原尺寸分块。

## 兼容范围与限制

- 当前基线为 **标准 PSD、8 位 RGB**。PSB、16/32 位、CMYK 等会明确拒绝，并提示转存 RGB 副本或 PNG。标准 PSD 自身的格式限制仍然存在。
- 高级混合模式、PSD 蒙版、剪贴关系、图层效果、调整图层、独立填充透明度等尚未重建；检测后列出提示并随工程保留。可导出已应用效果的 PNG 保留外观。文字与智能对象使用 PSD 中已有的像素副本。
- 没有 Photoshop 内容绘制、像素编辑或完整 ICC 色彩管理。复杂的真实美术 PSD 仍需逐份对照，不能保证与 Photoshop 完全一致。
- 分组逻辑原点使用文档坐标原点，子层保留原位置；跨组拖动会换算坐标以保持几何位置，移入不同透明度的分组会改变合成外观。
- 磁盘保存原图、无损原尺寸分块与预览。解析时原 PSD 字节与单层缓冲仍占内存，这不是流式读取任意大文件。受管图像纹理的默认 RGBA 预算为 192 MiB，驱动、图形缓冲、滤镜池及解码副本另计。
- 大量半透明全尺寸层仍有像素叠加成本。预算紧张时，未选中层可能暂用较低清晰度；选中目标层再放大检查细节。切换清晰度时分块会逐步出现。
- 纹理占用是 RGBA 估算，**不是显卡报告的总显存**。后台峰值来自采样，实际瞬时峰值可能更高。长音乐仍使用完整 PCM 缓冲，会占用较多内存。
- 尚未实现 SVG、Circle/Slider、判定、贝塞尔路径、动态蒙版、镜头、打击音效、视频导出或安装包。不会自动开始阶段 3。

## 实际验证

素材均为脚本生成的**有效 PSD 文件**，通过正常后台导入路径处理，并非直接伪造工程数据。它们不是 Photoshop 制作的真实插画；全尺寸素材使用易压缩色块，不能代表高噪声、大文件或复杂效果 PSD。

- 小型 PSD：读取画布截图像素，验证位置、顺序、分组重叠透明度，验证图层拖拽、锁定、变换、撤销和保存恢复。
- 典型工程：6000 × 6000、1 个全尺寸背景＋99 个裁剪图层、10 个分组（含嵌套）；验证所有分组实际成像、高清细节、排序、音乐与保存恢复。
- 极端尺寸压力：100 张各为 6000 × 6000、非零透明度的重叠层，加 2 个分组。全部解码体量为 14.4 GB（约 13.4 GiB），与典型裁剪工程分开记录。
- 单元测试覆盖序列化、时间、跨组变换、裁剪、预览降采样、原尺寸分块像素一致性、文件安全和资源生命周期。

典型测试结果在 `test-results\stage2\report.json`，全尺寸压力结果在同目录的 `stress-report.json`，详细记录为 `*-performance.json`，实际截图为 `editor.png`、`large-detail.png` 等。第一阶段回归在 `test-results\e2e\report.json`。短时帧率只反映本机与对应窗口，**不承诺长期稳定 60 FPS**，也不代表未来路径动画性能。

阶段 2 首次验收：类型检查、61 项单元测试、构建、第一阶段 15 组窗口回归、阶段 2 含压力测试的 11 组窗口验证均通过，窗口脚本未记录到页面错误。测试机为 Windows、i7-13700HX、约 24 GB 内存。另验证了 Windows 应用数据目录重定向时的正常启动与会话切换。

删除与画板裁切修改后：类型检查、66 项单元测试、构建、新增 8 组编辑窗口测试、第一阶段 15 组及阶段 2 典型 100 层的 10 组窗口回归均通过。编辑测试报告在 `test-results\editing\report.json`，截图为同目录的 `cropped.png` 和 `reopened.png`；本次未重跑全尺寸 100 层解码压力测试。

| 生成 PSD 工况 | 后台导入 | 后台 RSS 采样峰值 | 全图预览受管纹理估算 | 全图 / 原尺寸短时 FPS |
| --- | ---: | ---: | ---: | ---: |
| 6000 × 6000，典型裁剪 100 层＋10 组 | 2.11 秒 | 366.7 MiB | 5.0 MiB | 60.0 / 60.0 |

## 开发与重跑测试

修改源代码后，在本文件夹的 PowerShell 中依次执行：

```powershell
npm run check
npm run test:e2e
npm run test:images
npm run test:edits
npm run test:stress
```

`check` 包含类型检查、单元测试和生产构建；`test:e2e` 检查第一阶段；`test:images` 检查 PSD/PNG 与典型 100 层；`test:stress` 另外执行 100 张全尺寸图层压力测试，耗时更长。窗口测试请依次执行，避免争用同一结果目录。自动化仅替代文件选择的路径，实际读写、解码、渲染与音频均使用正式实现。

`test:edits` 专门验证图层/分组/音频删除、撤销重做、播放联动、画板裁切的实际像素和保存恢复。

完成全尺寸测试后，可用 `node scripts/verify-dense-save.mjs` 单独复查已保存大工程的属性修改、另存为和重新打开，无需再次解码 PSD；结果在 `dense-reopen-report.json`。

音频回归生成 WAV/MP3/OGG，需要本机 FFmpeg（可用 `FFMPEG_PATH` 指定）；应用本身不依赖它。重新安装用 `npm install`，自动刷新的开发模式用 `npm run dev`。

## 代码入口

- `src/shared`：工程模型、校验与桌面接口。
- `src/core`：时间、坐标、层级变换、分块、资源与性能统计。
- `src/application`：编辑命令与历史。
- `src/main/images` / `image-worker.ts`：后台 PSD/PNG 解码、裁剪与分级分块。
- `src/main/projects` / `src/preload`：安全文件服务、素材完整性检查与隔离通信。
- `src/renderer/canvas`：图层渲染与纹理缓存；`panels`：图层树与属性；`audio` / `timeline`：音乐和时间轴。
- `tests` / `scripts`：单元测试、素材生成和实际 Electron 窗口验收。
